# Sistema de Gestão de Impressões e Suprimentos

Aplicação Desktop para gráficas de comunicação visual: cadastro de clientes, ordens de serviço com
orçamento por m², fila de impressão e controle de estoque de materiais.

Projeto da disciplina de Análise e Projeto de Sistemas.

**Tecnologias:** Python, Tkinter e SQLite.
